# s3c6410-bare-metal

All the code are compiled and tested under the ARM GCC 7.5 toolchain.

GCC 7.5.0 is the final major pre-built Linaro/GNU toolchain series that offered official 32-bit (i686) Linux-hosted binaries

This version of toolchain can be download at :

    https://developer.arm.com/Downloads/-/Legacy%20Linaro%20GNU%20Toolchains
